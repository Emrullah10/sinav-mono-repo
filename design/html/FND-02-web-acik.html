Hedef Süre: 2 dk 15 sn 14 / 80
OKUMA PARÇASI (PASSAGE) 112 Kelime · Literata 17px / 27px

Recent interdisciplinary investigations into cognitive linguistic acquisition suggest that bilingual adults exhibit higher neural elasticity when processing structurally divergent idioms. Contrary to classical assumptions stating that syntactic frameworks solidify after adolescence, contemporary neuroimaging reveals continuous synaptic adaptation during targeted second-language immersion. Consequently, structured lexical retention models remain highly effective across diverse age brackets.

4. Harf Aralığı, Leading ve Okuma Ergonomisi Rehberi

Göz hareketlerini (sakkad) kolaylaştıran ve sınav performansını koruyan temel kurallar.

WCAG 2.1 AAA
view_column

CPL Kuralı

Sınav metinlerinde optimal satır genişliği 65-75 karakter arasında kesin sınırlandırılmıştır. 80 karakteri aşan uzun satırlar adaylarda satır atlama (line skip) ve geriye dönüş okuma hatasına yol açar.

Maksimum Sütun: 680px (~70ch)
format_line_spacing

Leading (Satır Yüksekliği) Oranı

Okuma serif metinlerinde (Literata) font boyutunun en az 1.58 - 1.62 katı satır yüksekliği uygulanır. Bu geniş hava sahası, zorlu akademik kelimelerde gözün kelime öbeklerini ayrıştırmasını sağlar.

17px Font = 27px Line-Height (1.59x)
spellcheck

Türkçe Karakter Eşitliği

Yumuşak g (ğ), noktalı büyük i (İ) ve ş harflerinin dikey optik hizalaması İngilizce ASCII fontlarla tam dengeli olmalıdır. Aksanlı harflerde üst/alt satır çakışması (clipping) sıfırdır.

Destek: ğ, Ş, İ, ı, ç, Ö, ü tam glif seti

5. CSS Tokenları ve Font Kütüphanesi Aktarımı

Geliştiriciler için doğrudan projeye eklenebilir CSS değişkenleri ve tipografi token seti.

yds-typography-tokens.css Design System v1.2 
/* ==========================================================================
   YDS TASARIM SISTEMI - FND-02 TIPOGRAFI CSS TOKENLARI
   ========================================================================== */

:root {
  /* Font Aileleri */
  --yds-font-sans: 'Figtree', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif;
  --yds-font-serif: 'Literata', Georgia, 'Times New Roman', serif;
  --yds-font-display: 'Bricolage Grotesque', sans-serif;

  /* Display & Baslik Tokenlari */
  --yds-text-display-l: 700 3.5rem/3.75rem var(--yds-font-display);      /* 56px / 60px */
  --yds-text-display-m: 700 2.5rem/2.75rem var(--yds-font-display);      /* 40px / 44px */
  --yds-text-heading-1: 600 2.0rem/2.5rem var(--yds-font-sans);          /* 32px / 40px */
  --yds-text-heading-2: 600 1.5rem/2.0rem var(--yds-font-sans);          /* 24px / 32px */
  --yds-text-heading-3: 500 1.25rem/1.75rem var(--yds-font-sans);        /* 20px / 28px */
  --yds-text-title: 600 1.0rem/1.375rem var(--yds-font-sans);            /* 16px / 22px */

  /* UI & Standart Metin Tokenlari */
  --yds-text-body-l: 400 1.125rem/1.75rem var(--yds-font-sans);          /* 18px / 28px */
  --yds-text-body-m: 400 1.0rem/1.5rem var(--yds-font-sans);             /* 16px / 24px */
  --yds-text-body-s: 400 0.875rem/1.25rem var(--yds-font-sans);          /* 14px / 20px */
  --yds-text-label-l: 600 0.875rem/1.25rem var(--yds-font-sans);         /* 14px / 20px */
  --yds-text-label-m: 500 0.75rem/1.0rem var(--yds-font-sans);           /* 12px / 16px */
  --yds-text-caption: 400 0.75rem/1.0rem var(--yds-font-sans);           /* 12px / 16px */
  --yds-text-overline: 700 0.6875rem/0.875rem var(--yds-font-sans);      /* 11px / 14px */

  /* Akademik Sinav & Okuma Tokenlari (Literata Serif) */
