Bölüm 2 · Düğme Etkileşim ve Durum Matrisi (State Matrix)

WCAG 2.1 AAA Seviyesi Onaylı
Durum (State) Birincil (Primary 44px) İkincil (Secondary 44px) Yıkıcı (Destructive 44px) Teknik Kural Açıklaması
1. Varsayılan
Default / Rest
 Temel başlangıç durumu. 1px solid #DAE1E0 ince sınır veya #0E6A6E kurumsal petrol zemin.
2. Üzerine Gelme
:hover State
 İmleç bileşen üzerindeyken zemin tonu koyulaşır (#094B4E veya #DAEBF4). Göze çarpan sakin geçiş.
3. Basılı / Etkin
:active State
 Kullanıcı tıkladığında buton mikro ölçekte (0.98) küçülür ve sınır vurgusu kalınlaşır (Taktil Geri Bildirim).
4. Odak Halkası visibility
:focus-visible
 Klavye (Tab) gezinmesinde 2px kalınlığında, 2px boşluklu #0E6A6E erişilebilirlik halkası açılır.
5. Pasif / Devre Dışı
:disabled
 Tıklanamaz ve odaklanamaz. not-allowed imleç atanır; kontrast düşürülerek etkisizlik ifade edilir.
6. Yükleniyor / İşleniyor
aria-busy="true"
 Asenkron sunucu işleminde 1.5px geometrik çizgi spinner döner. Buton genişliği korunur, metin güncellenir.
