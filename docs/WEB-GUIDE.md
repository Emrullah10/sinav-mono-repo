# Web uygulaması kılavuzu (sinav-web-app)

Bağlayıcı: `docs/PLAN-P0.md` (§4 ekran→uç eşlemesi), `docs/tasarim-dokumani.md` (§13–14 ekran ayrıntıları, §8 bileşenler, §9 metin tonu), `docs/api/*.md` (uç sözleşmeleri), şablon §16. Yalnız JS/JSX. **Test dosyası yazılmaz.** Arayüzde **sabit/mock veri yok**: her ekran verisini API'den alır (`@api`).

## Görsel kaynak
Her ekranın çizimi: `design/html/<KOD>-web-acik.html`, `-web-koyu.html` (ve `-mobil-*`); ekran görüntüsü `design/shots/<modül>/<KOD>-web-acik.png` (Read aracıyla görüntüyü aç; HTML'i de oku: düzen, metin, sıra, durumlar). Çizim Tailwind/Material Symbols ile yapılmış taslaktır; **birebir kopyalama**: bileşenleri `@components` ve token'lardan (CSS değişkenleri `--color-*`, `--space-*`, `--radius-*`, sınıflar `.t-heading-1` …) kur. Çizimdeki sabit rakam/isimler yer tutucudur; gerçek veri API'den. Metinler çizim/tasarım dokümanıyla aynı tonda, i18n anahtarlarıyla (hardcode metin yasak).

## Yapı ve kurallar
- Özellik klasörü: `src/features/<alan>/{pages,components,hooks,routes.jsx}`. `routes.jsx` → `export default [{ path, element, layout: 'app'|'focus'|'auth'|'cms'|'bare', access: 'public'|'session'|'learner'|'permission', permission? }]` — `router/App.jsx` otomatik yükler (başka dosyaya dokunma). Sayfa bileşenlerini `lazy(() => import('./pages/X'))` ile ver. Yol sabitleri `shared/constant/route-paths.js`'te (yeni yol gerekiyorsa EKLE, mevcutları değiştirme); `access: 'session'` misafir dahil, `'learner'` kayıtlı öğrenci (misafir /kayit'a gider).
- Metin: `shared/translation/keys/<alan>Keys.js` → `export default { 'anahtar': { tr, en } }` (dosya adı `*Keys.js`, otomatik toplanır). Her iki dil zorunlu. Enum etiketleri `enums.<enum>.<değer>` anahtarları paylaşılan pakette (`packages/i18n/keys/enums*Keys.js`); yoksa kendi dosyana ekle. `t('apiErrors.KOD')` hata çevirileri paylaşılan pakette.
- Veri: `import api from '@api'` (SDK; fonksiyon adları `docs/api/*.md` ve `packages/client-sdk/src/*.js`'te). Okuma `useApiQuery(['alan','eylem',params], () => api.fn(...))`, yazma `useApiMutation(fn, { successMessage, onSuccess })` (`@hooks`); yanıt zarfı `data.data` otomatik açılır. Mutation sonrası ilgili anahtarları `queryClient.invalidateQueries`. Anahtarlar kararlı diziler. Yükleme: `Skeleton`/`BubbleLoader` (400 ms'den kısa yüklemede gösterme gerekmez), boş durum `EmptyState`, hata `ErrorState` (retry). Her ekran boş/yükleniyor/hata durumlarını işler.
- Stil: bileşen yanında `X.module.scss`; renk/boşluk/köşe yalnız token CSS değişkenlerinden (hex yasak). Mixin'ler `@use '@styles/globals' as *;` (`up(md)`, `down(sm)`, `focus-ring`). Telefon (390), tablet, masaüstü (1440) düzenleri; kırılma noktaları tasarım §7.2. Koyu tema ilk günden: yalnız semantik token kullan. Dokunma hedefi ≥44px; odak halkası görünür; `prefers-reduced-motion`'a uy.
- Bileşenler `src/components/*` (Button, IconButton, Card, Chip, ProgressBar, ProgressRing, ScoreBand, OptionRow, TextInput, Select, Switch, Segmented, Tabs, Modal, Banner, EmptyState, ErrorState, Skeleton, BubbleLoader, ListRow, PageHeader, Avatar) — `import Button from '@components/Button/Button'`. Eksik ortak bileşen gerekirse `src/components/<Ad>/<Ad>.jsx` ekle (mevcutları bozma; API'yi genişletirken geriye uyumlu kal). Özelliğe özgü bileşenler feature klasöründe.
- İkonlar: `lucide-react`. Yazı: `.t-*` sınıfları (display-l … numeric-m), okuma metni `.reading` + `.t-reading-m`; sayılar `tnum` (tabular). Türkçe biçimlendirme: sayı `toLocaleString('tr-TR')`, tarih `dayjs` (tr), yüzde "%42", büyük harf `toLocaleUpperCase('tr-TR')`, para "349 TL".
- Oturum: `useAuthStore` (user, permissions, status); misafir `isGuestUser(user)`. Çıkış `signOut()` (`@shared/auth/session`), misafir açma `ensureSession()`, giriş yanıtı `applySession(response)`.
- Erişilebilirlik: etiketli form alanları, ikon düğmelerde `aria-label`, durum renk+ikon+metin, klavye kısayolları (A–E, Enter, H, F, X, ←→ — tasarım §16.7; metin alanı odaktayken devre dışı), canlı bölgeler.
- Erken çıkış kuralları: fazla soyutlama yapma; çizimde olmayan özellik ekleme; P1–P3 öğeleri gezinmede "Yakında" ile pasif.

## Çalıştırma ve doğrulama
- Backend çalışıyor olmalı (`pm2 status`; yoksa `bash scripts/start-backend.sh`). Web: `npm run dev:local` (Vite :3000 → gateway :2000). Bu sandbox'ta Vite dev sunucusu başlatıp Playwright ile gez: `playwright-core` kurulu, Chromium yolu `~/Library/Caches/ms-playwright/chromium-*` (ör. `chromium.launch({ executablePath })` ya da playwright-core'un varsayılanı); betikleri scratchpad klasöründe tut (repo'ya EKLEME). Her ekranı 1440×900 ve 390×844'te, açık ve koyu temada (`localStorage theme-storage` / `data-theme` attribute) aç, ekran görüntüsünü al ve `design/shots`'taki çizimle yan yana gözle karşılaştır; konsol hatası ve 4xx/5xx istek sayısı 0 olmalı. Gerçek akışı uçtan uca yürüt (gerçek API + seed veri).
- Kontroller: `npm run lint` (kök), `npm run build`. Çalışan bir akışı "çalışıyor" demeden önce tarayıcıda gör.
- Git: commit atma. Başkasının dosyasını düzenleme; ortak dosyalarda (`route-paths.js`, `components/*`, `store/*`) yalnız ekleme yap.
